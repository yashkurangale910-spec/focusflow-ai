# Neural Coach - Quick Test Guide

## 🧪 Test the Enhanced Chatbot

### Basic Understanding Tests ✅

1. **"cant start my work"**
   - Should: Understand task initiation difficulty
   - Should: Offer 5-minute rule + micro-steps
   - Should NOT: Say "I don't understand"

2. **"to much stuff to do help"**
   - Should: Understand overwhelm
   - Should: Offer prioritization framework
   - Should: Mention AI Daily Planner

3. **"brain no work tired"**
   - Should: Understand fatigue/executive dysfunction
   - Should: Suggest rest or energy-matched tasks
   - Should: Validate feeling

### Personalization Tests 🎯

4. **"Hi! I'm on day 15 of my streak"**
   - Should: Use 7-30 day template
   - Should: "Wow! 15 days in a row - that's serious commitment!"

5. **"I'm feeling stressed today"**
   - Should: Match mood template
   - Should: "When stressed, our brains need simple, clear next steps"

6. **"I've completed 60 hours of focus time"**
   - Should: Use 50-100 template
   - Should: "Seriously impressive - expert-level commitment!"

### Advanced Scenarios 🔧

7. **"I tried Pomodoro but it didn't help"**
   - Should: Validate attempt
   - Should: Diagnose what got in the way
   - Should: Offer alternatives (shorter intervals, body doubling)

8. **"Nothing works for me. I've tried everything"**
   - Should: Empathize
   - Should: Reframe as learning
   - Should: Suggest system over willpower

9. **"I can't do this anymore. I'm done"**
   - Should: Validate feelings
   - Should: Give permission to rest
   - Should NOT: Push productivity

### Complex Situations 📊

10. **"I worked 6 hours straight yesterday and now I can't focus"**
    - Should: Recognize hyperfocus crash
    - Should: Distinguish immediate (rest) vs future advice (Pomodoro)
    - Should: Mention Neural Recovery protocol

11. **"Why do I always procrastinate? I hate myself for it"**
    - Should: Reframe as neurological not character flaw
    - Should: Explain dopamine system
    - Should: Offer 4 specific strategies

12. **"I keep opening social media when working"**
    - Should: Normalize (dopamine seeking)
    - Should: Recommend Browser Sentinel feature
    - Should: Give immediate + long-term strategies

### Edge Cases 🌟

13. **"help"** (vague)
    - Should: Ask clarifying question
    - Should: "Are you struggling to start, stay focused, or manage time?"
    - Should: Provide example issue + solution

14. **"stuck"** (one word)
    - Should: "I hear you're feeling stuck. Let's figure this out together"
    - Should: Offer to help even without details

15. **"THIS IS STUPID I CANT FOCUS"** (frustrated)
    - Should: Recognize frustration
    - Should: Validate + reframe
    - Should: Provide specific strategy

## Quality Checklist for All Responses ✨

Every response should:
- [ ] Show understanding of user intent
- [ ] Include at least ONE actionable step
- [ ] Use encouraging tone
- [ ] Be specific, not vague
- [ ] Acknowledge context if provided (streak/mood/hours)
- [ ] Reduce overwhelm, not increase it
- [ ] End with encouragement or question

## What Should NEVER Happen ❌

- ❌ "I don't understand" without attempting to help
- ❌ Grammar or spelling corrections
- ❌ Vague advice like "just focus harder"
- ❌ Overwhelming lists of 10+ strategies
- ❌ Judgment about productivity struggles
- ❌ Ignoring user's emotional state

## Quick Reference: When to Mention Features

| User Says | Feature to Mention |
|-----------|-------------------|
| "Keep getting distracted" | Browser Sentinel |
| "Can't start alone" | Co-Working Rooms |
| "Too many tasks" | AI Daily Planner |
| "Need motivation" | Focus Battles + Gamification |
| "Noise bothers me" | Neural Soundscapes |
| "Forget tasks" | Mood Tracking + Analytics |

## Advanced Feature Test

16. **"I want to compete with others for motivation"**
    - Should: Mention Focus Battles
    - Should: Explain competitive element
    - Should: Mention leaderboards

17. **"I need background noise to focus"**
    - Should: Recommend Neural Soundscapes
    - Should: Mention lo-fi, rain, white noise options

18. **"I always forget what I need to do"**
    - Should: Suggest visual task boards
    - Should: Mention working memory challenges
    - Should: Recommend external brain systems

## 📦 Installation & Setup

### 1. Prerequisite
- Node.js installed
- MongoDB Atlas account
- Neural Engine API Key

### 2. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/focusflow-ai.git
cd focusflow-ai
```

### 3. Backend Setup
```bash
cd backend
npm install
# Create a .env file with:
# MONGODB_URI=your_mongodb_connection_string
# NEURAL_ENGINE_KEY=your_key
# JWT_SECRET=random_secure_string
npm run dev
```

### 4. Frontend Setup
```bash
cd ../frontend
npm install
npm run dev
```
